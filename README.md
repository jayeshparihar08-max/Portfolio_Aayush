# Aayush - Portfolio

Portfolio website for Aayush, showcasing Video Editing and Graphic Design work.

## Tech Stack
- HTML5
- CSS3 (Variables, Grid, Flexbox)
- Vanilla JavaScript
- GSAP (GreenSock Animation Platform)

## Setup
To run the project locally, you can use any local web server (like `live-server`, `http-server`, or the Live Server VSCode extension).

If you have Node.js installed, you can use `npx serve`:
```bash
npx serve .
```

## Structure
- `/src/css/`: Stylesheets including variables and base setup.
- `/src/js/`: Main logic and animation utilities.
- `/src/assets/`: All media files (images, videos, etc.)
